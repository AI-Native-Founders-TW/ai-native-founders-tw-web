文字對比要通過 WCAG AA：深底上的內文用 `snow-50`，次要文字不要低於 `#B8C0E0`。

## 3. 調性

| 要 | 不要 |
|---|---|
| 歡迎、好奇、一起玩（Speedrun、流派） | 加速器、VC 的菁英與募資感（「太資本主義的感覺」） |
| 誠實：還在建立中的就說還在建立 | 假裝有很多資源、mentor、成果 |
| AI-Native、有質感 | 過度科技炫技、難讀 |
| 給新人與前輩都看得懂 | 只講給已經準備好募資的人 |

## 4. 視覺概念：Speedrun × 流派

逐字稿中水球把創業比喻成遊戲 speedrun 與《流亡黯道》的流派（0:31、0:58），可以成為整站的視覺語言：

- **流派卡**：像角色職業卡，欄位為「適合誰／前期成本／辛苦程度／參考經驗」。V1 只放範例並標示「整理中」。
- **Speedrun 路線**：加入流程畫成關卡（加入 Discord → Star → 閱讀 → 提交自介）。
- **貢獻者徽章**：每位貢獻者的頭像與貢獻類型（文案、設計、程式、資訊貢獻）。

遊戲化只用在呈現，不做排行榜或積分（避免變成強制參與的壓力，憲法第 13 條）。
